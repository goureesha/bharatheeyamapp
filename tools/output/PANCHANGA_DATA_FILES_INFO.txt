================================================================
  BHARATHEEYAM PANCHANGA DATA FILES
  District Coverage Guide
================================================================

Download the .bdat file for your district/city.
Import it in the app: Settings > Panchanga Data > Import .bdat

Each file covers 20 years of pre-computed panchanga data
including Tithi, Nakshatra, Yoga, Karana, Sunrise, Sunset,
Chandra Masa, Soura Masa, and Samvatsara.

Maximum sunrise error within any zone: less than 5 minutes.
