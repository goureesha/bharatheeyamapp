# Upanishads Translation Style Audit Report

This report provides a status audit of the translation style across all Upanishad books in the library. It classifies chapters into:
- **Fully Shloka-by-Shloka**: Chapters where each shloka has its own Shabdartha and Bhavartha block (or the chapter has <= 2 shlokas and has corresponding translations).
- **Few Blocks (Grouped)**: Chapters that contain multiple shlokas but only have a few translation blocks (shlokas are grouped together).
- **Single Block**: Chapters that only have one single Shabdartha and Bhavartha block at the end (summary style).

## Overall Summary

- **Total Upanishad Books**: 229
- **Total Upanishad Chapters**: 499
- **Chapters Fully Shloka-by-Shloka**: 349 (69.9%)
- **Chapters with Few Blocks (Grouped)**: 3 (0.6%)
- **Chapters with Single Block (Summary)**: 147 (29.5%)
